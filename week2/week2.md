# 2주차 실습 — 변환과 행렬
## Task 1 — 실제 비율로 만들기
### 대상 인공위성
국제우주정거장(ISS)을 선택

### 실제 수치 및 기준
- 지구 반지름: 약 6,371 km
- 달 반지름: 약 1,738 km
- 지구-달 평균 거리: 약 384,400 km
- ISS 고도: 433.8 km
- ISS 크기: 약 109 m

1.거리의 단위는 지구 반지름을 1로 두는 방식으로 정규화
2. 실제 km 단위를 그대로 사용하면 값이 너무 커져 실습 화면에서 변환 결과를 다루기 어렵기 때문에, 지구 반지름을 기준 단위로 사용

### 적용한 변환

#### 지구
- 크기(균등): 1

#### 달
- 회전 Rz: t
- 이동 T: (60.34, 0, 0)
- 크기(균등): 0.273
- 회전 Rz: pi

#### ISS
- 회전 Rz: t
- 이동 T: (1.068, 0, 0)
- 크기(균등): 0.000017
- 회전 Rz: pi

### 질문

1. 거리의 단위를 무엇으로 정했는가? 왜 그렇게 정했는가?
지구의 반지름을 1로 고정하였다. 실제 거리를 km 단위 그대로 사용하면 지구-달 거리가
384,400처럼 매우 큰 값이 되므로 변환 값을 다루기 불편하다.(확인하기에도 어려움 존재) 따라서 각 천체의 실제 비율은 유지하면서 숫자를 단순화하기 위해 지구 반지름을 기준 단위로 사용하였다.

2. 숫자가 커서 생긴 문제가 있었는가? 있었다면 무엇인가?

있었다. 지구 반지름을 1로 두어도 달의 궤도 반지름은 약 60.34가 됐다.
실습 화면의 기본 축 범위가 ±3이기 때문에 달이 화면에서 매우 멀리 떨어져 보였으며,
달의 크기와 방향을 확인하기 어려웠다. 또한 ISS는 실제 크기 비율이 매우 작아서
화면에서 거의 보이지 않았다. (확대를 하여도 보이지 않아 어려움이 있다.)

3. 달·위성이 지구를 향하게 만든 것은 어느 변환 단계 덕분인가?

마지막에 적용한 Rz(pi) 회전 변환 덕분이다.
pi 라디안은 180도 회전을 의미하며, 달과 ISS의 로컬 +X 방향을 반대로 돌려
지구 방향을 향하도록 만들었다.
