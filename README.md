# 나만의 태양계 (My Solar System)

## 소개
행성들이 우주쇼를 펼치는 것과 같은 태양계를 만들고 싶다. (실제과 상상 속 태양계의 융합)

## 실행 방법
1. 저장소를 다운로드하거나 clone한다.
2. `index.html`을 브라우저의 로컬 서버에서 실행한다.
3. WebGL2를 지원하는 브라우저에서 확인한다.

## Copilot 사용
- 사용한 프롬프트: "내가 원하는 배경색을 출력하는 RGB 색상 지정해줘."
- 수정한 내용: 생성된 코드의 `gl.clearColor()` 값을 수정하여 내가 원하는 어두운 네이비 우주 배경색으로 변경했다.

## 검증 실험

### 실험 1 — clearColor 변경
- 예측: 배경이 주황색으로 바뀔 것 같다.
- 결과: 예상대로 배경이 주황색으로 바뀌었다.
- 왜: `gl.clearColor()`의 앞 세 값은 각각 RGB(빨강, 초록, 파랑)를 의미한다. 빨강을 1.0, 초록을 0.5, 파랑을 0.0으로 설정했기 때문에 주황색이 나타났다.

### 실험 2 — resize() 제거
- 예측: 캔버스의 실제 해상도가 브라우저 크기에 맞춰지지 않아 화면 크기나 선명도에 문제가 생길 것 같다.
- 결과: 브라우저 창의 크기를 변경해 보았지만 눈에 띄는 차이가 없었다.
- 왜: CSS의 `width: 100vw`, `height: 100vh`가 캔버스를 화면 전체 크기로 표시하고 있고, 현재는 단색 배경만 출력하고 있어서 실제 캔버스 해상도 차이를 눈으로 확인하기 어려웠다.

### 실험 3 — WebGL2 → WebGL1
- 예측: 지금은 단순히 배경색만 출력하고 있어서 WebGL1로 바꿔도 화면은 똑같이 보일 것 같다.
- 결과: `webgl2`를 `webgl`로 변경해도 화면에는 눈에 띄는 변화가 없었고 정상적으로 실행되었다.
- 왜: 현재 코드는 배경색을 설정하고 캔버스를 지우는 기본 기능만 사용하기 때문에 WebGL1에서도 동일하게 동작한다.
